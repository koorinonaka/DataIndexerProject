    Rename rows. References hold.

    DataIndexer is a game data management plugin for UE5. Every row is identified by a GUID (FDataIndexerPrimaryKey), so references survive renames, moves, and reimports. A type-safe C++ / Blueprint API and a centralized Schema keep maintenance costs low as your data grows.

    1. GUID-based PrimaryKeyChange a key's name freely — Blueprint and code references stay intact.
    2. Key usage trackingSee which assets and code reference a given row, directly in the editor.
    3. Per-row overridesOverride only specific rows in a child repository — a capability UCompositeDataTable didn't have.
    4. Secondary queriesLook up rows by an index from Blueprint or C++ at near-O(1) efficiency.

    The same data. C++ or Blueprint.

    API Reference → 
    USTRUCT(BlueprintType)
struct FItemRow
{
    GENERATED_BODY()

    UPROPERTY(EditAnywhere, BlueprintReadWrite) FText       DisplayName;
    UPROPERTY(EditAnywhere, BlueprintReadWrite) EItemType   Type;
    UPROPERTY(EditAnywhere, BlueprintReadWrite) EItemRarity Rarity;
    UPROPERTY(EditAnywhere, BlueprintReadWrite) int32       BaseValue = 0;
};
using FItemInterface = DataIndexer::TNativeSchemaInterface<FItemRow>;

if (const FItemRow* Row = FItemInterface::FindRow(Repository, PrimaryKey))
{
    FText Name = Row->DisplayName;
}

FItemRow Filter; Filter.Rarity = EItemRarity::Rare;
for (const FDataIndexerPrimaryKey& K :
     FItemInterface::GetPrimaryKeys(
         Repository, UItemSchema::ByRarityIndex(), Filter))
{
    Process(*FItemInterface::FindRow(Repository, K));
}
    Types in one place
    C++ queries are type-safe via TNativeSchemaInterface<T>. Blueprint uses Get Row nodes for the same data.
    Auto-validated on save and cook
    Row-to-row relations and referential integrity checked automatically. Catch data inconsistencies before runtime.
    Near-O(1) reverse lookup
    Declare an Index on the schema. Attribute-based search stays fast as row count grows.

    Existing DataTable projects can migrate incrementally — see the Migrate from DataTable guide.
